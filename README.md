# Government Service Portal

A web-based system where:

- Citizens can apply for government services
- Officers can approve or reject applications
- Users can track application status in real time

---

## 🚀 Tech Stack
- Python
- Flask
- SQLite
- HTML & CSS

---

## 🔧 Features
- Role-based login (Citizen / Officer)
- Service application system
- Application status tracking
- Approval / Rejection workflow

---

## ▶️ How to Run

1. Install dependencies:
   pip install flask

2. Run the app:
   python app.py

3. Open in browser:
   http://127.0.0.1:5000
